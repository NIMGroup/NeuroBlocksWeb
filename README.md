# NeuroBlocks Website Prototype

这是一个纯静态、可直接部署的 NeuroBlocks 官网原型。

## 本地预览

```bash
cd neuroblocks_site
python3 -m http.server 8080
```
然后浏览器打开 `http://localhost:8080`。

## 部署
可直接上传到 GitHub Pages、Vercel、Netlify、Webflow 自定义代码环境，或任何静态站点服务器。

## 目录
- `index.html`：完整单页官网（含 CSS / JS / 交互）
- `assets/*.webp`：优化后的 NeuroBlocks 视觉素材
- `assets/*.mp4`：网站循环演示视频
