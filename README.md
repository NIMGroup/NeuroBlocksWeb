# NeuroBlocks Website — Interactive Native Web Edition

这是 NeuroBlocks 官网的原生交互版，不直接嵌入 PPT 图片或此前附件图片。

## 核心特性
- 纯 HTML/CSS/JavaScript，无框架依赖
- 互动式模块化头戴系统首屏
- 八层系统架构探索器
- Hardware Blocks 产品配置器
- SkillOS / NeuroAgent 工作流生成器
- EEG / EMG / PPG / IMU 模拟实时波形
- Signal Quality 动态热图
- 9 类应用场景交互探索器
- 9 个 Solution Kits
- Research / Clinical Research 双模式
- 产品范式对比矩阵
- 生态飞轮与商业模式

## 说明
页面中的实时波形、质量指标、KPI 均为交互演示用模拟数据，不代表真实受试者、临床结果或业务指标。

## 运行
直接打开 `index.html`，或：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。
