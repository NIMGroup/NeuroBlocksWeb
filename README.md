# NeuroBlocks Website v3

第三轮优化版：
- 不使用 PPT 整页图片；新增真实感场景与硬件视觉资产
- 交互式硬件组装、SkillOS / NeuroAgent、12 类应用场景、14 个解决方案
- 模拟实时 EEG/EMG/PPG/IMU 波形、QC 热图、频谱瀑布、事件流与生态网络可视化
- Research / Developer 与 Clinical Research 模式分离
- 纯静态 HTML/CSS/JS，可直接部署到 GitHub Pages / Vercel / Netlify

## 运行
直接打开 index.html，或执行：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000

注：实时波形、频谱、质量指标、生态网络和 KPI 均为产品交互演示/模拟数据，不代表真实受试者、临床效果或业务数据。
